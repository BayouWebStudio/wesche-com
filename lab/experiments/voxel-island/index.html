Read before comparing

The setup, the repairs, the limits.

Successful displayed runs requested thinking ON, xhigh, temperature 0.7 and a 120,000-token output budget. Different model variants and engines mean this is not a controlled quantization-only experiment.

AEON attempts 1–2 failed because of harness limits (an output cap and a client timeout). Attempts 3–4 are distinct model failures: repetitive degeneration, then a natural stop with no final content. These must not be counted as four model failures.

The Mac scene includes a two-line duplicate-identifier repair. Flash-Next has no recorded repair. This excerpt preserves the original recordings’ motion; it is not a rendering-FPS benchmark.

Completion counts include reasoning. Reasoning character counts are not token counts. Saved wall times use each run’s original measurement boundary; no cross-model speedup or causal quantization claim is made here.
