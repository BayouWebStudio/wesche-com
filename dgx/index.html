MiniMax-M3 Deployment

MiniMax-M3-NVFP4 was served across four DGX Spark nodes using vLLM with tensor parallel size 4, ModelOpt FP4, B12X attention, B12X MoE, no Ray, RoCE fabric, and the community NVIDIA forum recipe based on lukealonso/MiniMax-M3-NVFP4 plus ghcr.io/tonyd2wild/vllm-m3-chthonic:nccl230u1.

Benchmark run: MiniMax-M3-NVFP4-vLLM-thinkOFF-64scen-v5c-4Spark-20260630-024756. TrueScore 85.10, median latency 5.45s, 27,877 output tokens across 64 scenarios.

Methodology

TrueScore = 0.55*Quality + 0.25*Calibration + 0.15*Reliability + 0.015*Efficiency + 0.035*Responsiveness

Spark-Bench uses deterministic grading: JSON schema checks, exact tool-argument matching, needle retrieval, executable Python and SQL tests, safety and robustness checks, multi-turn tool sequences, and pixel-based visual scoring. Speed is only 5 percent of the total score.
